## Mapping to the backend contract

1. **`proposer.sh` `run_agent()` (L394-499): a new `cursor|cursor:*` arm.**
   ```bash
   # sketch — not implemented
   overlay=$(mktemp -d); mkdir -p "$overlay"/{home,config,cache}
   HOME="$overlay/home" XDG_CONFIG_HOME="$overlay/config" XDG_CACHE_HOME="$overlay/cache" \
   CURSOR_API_KEY="$CURSOR_API_KEY" SPECSTRIDE_STDIN_FILE="$prompt_file" \
     run_with_idle_watchdog "$TIMEOUT" "$IDLE_TIMEOUT" "$cursor_bin" -p --force --trust \
       --workspace "$WORKDIR" --output-format stream-json --disable-auto-update \
       ${model:+--model "$model"} [--exclude-workspace-context] [--single-turn]
   ```
   - Prompt on stdin via `SPECSTRIDE_STDIN_FILE`, the same as the claude arm (argv dies at 128 KiB, verified live).
   - Pass `--force` **and** `--trust`: without them it auto-denies and exits early, which is safer than hanging.
   - Put `bin` behind `SPECSTRIDE_CURSOR_BIN` (default `agent`; the legacy name `cursor-agent` also exists).
   - Refuse `cursor:<slug>` together with `--model`, the same rule as dsh.
   - Overlaying `HOME` breaks the binary lookup if `agent` lives in `~/.local/bin`, so resolve the absolute path first with `command -v`.
   - Overlaying `HOME` also hides `~/.gitconfig` from the agent's shell. Keep the overlay config-only (`CURSOR_CONFIG_DIR` + `XDG_*`) and accept `~/.cursor/projects` writes, or copy `.gitconfig` in. This needs a spike.
   - `--single-turn` (hidden) stops the pass from waiting on background shells after the final turn. That is desirable, but it is internal.
2. **`run_iteration()` (L1408-1510):**
   - `cursor` always needs stream-json, because text mode is silent until the end and the idle watchdog would kill a long pass.
   - It needs **no** `--dangerously-skip-permissions`/`--disable-slash-commands`. The analogue of the skill-overflow guard is `--exclude-workspace-context` (hidden) or a documented equivalent. That is the P7 spike.
   - Add a `--provider-format cursor-stream-json` branch, with metadata.json like Prime's.

## Risks/unknowns

- **No credentialed run.** The stream sample, `usage` presence, the tool arg names, the auto-deny behaviour without `--force` and the 200 KiB acceptance are all unverified. The first roadmap item must be a credentialed spike.
- **Context auto-loading has no documented off switch.** `AGENTS.md`, `CLAUDE.md`, `.cursor/rules`, `.cursorrules` and skills load from the workdir. The only switch is the hidden, "internal" `--exclude-workspace-context`, which could be renamed or removed in any release. This is the skill-overflow risk. If the flag vanishes, the fallback is to accept the load and budget for it.
- **The critic cannot be proven tool-less.** There is no public `--no-tools`. `--mode ask` is read-only but still has read, grep and web tools; an empty workspace mitigates this. `--exclude-tools`/`--allowed-tools` are internal-only.
- **No direct inference API**, so the critic pays full agent overhead: system prompt, workspace scan and indexing (`--disable-indexing` is hidden).
- **Model ids are Cursor slugs.** The default `auto` is router-selected and non-deterministic. Context windows are unpublished per model, so C2 is unknown and the critic budget needs `SPECSTRIDE_CRITIC_CONTEXT_TOKENS`.
- **No cost in the stream** (tokens only). There is no max-turns concept or `error_*` result subtype, so every failure is "exit 1 + stderr + no result".
- **Release channel/stability:**
  - Date-hash versions come from a `/lab/` URL, and the installer always pulls the latest.
  - The CLI self-updates, so pass `--disable-auto-update` (hidden) or pin by invoking `versions/<ver>/cursor-agent` directly.
  - The docs contradict each other on write access without `--force` ("changes only proposed" vs "full write access in non-interactive mode").
- **Team admin policy** can disable Run Everything (`--force` then exits 1). Auto-review is server-classified.
- **Isolation caveat.** Some paths are hardwired to `homedir()/.cursor/{projects,worktrees}`, so full isolation needs a `HOME` overlay, which hides the operator's `~/.gitconfig` and `~/.ssh` from the agent's shell.
- **Size:** the 558 MB install and bundled sandbox binary matter for CI images.

## Verdicts

- **Proposer: go-with-caveats.** The headless path is documented. Stdin works, `--force --trust` is unattended, stream-json has a documented schema, auth failures exit fast with no hang, and a config overlay works. The caveats: a credentialed live spike first, and the context-exclusion flag is hidden.
- **Critic: go-with-caveats.** It must be the CLI (Cursor has no inference API), using `--mode ask` + `json` + an empty workspace. Strict tool-lessness and the context window stay unverified until a credentialed spike, and it needs `SPECSTRIDE_CRITIC_CONTEXT_TOKENS`.
