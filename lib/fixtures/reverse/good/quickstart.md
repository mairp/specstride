# Quickstart: tally

Every command below comes from `README.md` and `pyproject.toml`. **None was executed
by the reverse run.**

1. Install (not executed by the reverse run): `pip install .`
2. Count (not executed by the reverse run): `tally add coffee` → `coffee: 1`
3. Review (not executed by the reverse run): `tally show` → `coffee: 1`, `total: 1`
4. Use another file (not executed by the reverse run): `TALLY_FILE=/tmp/t.json tally show`
5. Test (not executed by the reverse run): `pytest`
